# Gym App (Expo + React Native)

App mínimo de academia para Android.

Requisitos:
- Node.js
- Expo CLI (`npm install -g expo-cli`) opcional

Instalação:

```bash
cd gym-app
npm install
npm run android
```

Arquivos principais:
- App.js
- src/screens/HomeScreen.js
- src/screens/WorkoutScreen.js
- src/screens/ProfileScreen.js
- src/components/ExerciseCard.js
